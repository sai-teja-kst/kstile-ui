title: Introduction
description: What kstile is and what's coming.
---

kstile is a registry of square, flat, tile-based components for
[shadcn/ui](https://ui.shadcn.com). You browse a component here, then install
its code into your own project with the shadcn CLI, so you own and can change
every line.

Start with the [Button](/docs/components/button/). More components are on the
way.
