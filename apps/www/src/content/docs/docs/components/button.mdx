## Installation

The button is React only, and needs Tailwind CSS v4. See
[Installation](/docs/installation/) for the full requirements.

## Examples

### Border width

The border is 3px by default. Pass `borderWidth` to change it, as a number of
pixels or any CSS length. Outline shows its border all the time. On filled
variants the border matches the fill until you hover.

<div class={row}>
  <Button borderWidth={2} variant="outline">2px</Button>
  <Button variant="outline">3px</Button>
  <Button borderWidth={6} variant="outline">6px</Button>
  <Button borderWidth="0.5rem" variant="outline">0.5rem</Button>
</div>

```tsx
<Button borderWidth={6} variant="outline">6px</Button>
<Button borderWidth="0.5rem" variant="outline">0.5rem</Button>
```

### Icon buttons

The icon sizes, `icon-xs`, `icon-sm`, `icon` and `icon-lg`, make the button a
square for a single icon. Icons are sized for you unless they set their own
`size-*` class. Give the button an `aria-label`, since it has no text.

### As a link

Use `asChild` to give another element the button's look.

<div class={row}>
  <ButtonLinkDemo />
</div>

```tsx
<Button asChild>
  <a href="/docs/">Back to the introduction</a>
</Button>
```

In Astro, `asChild` only works inside a React component. Children passed from an
`.astro` or `.mdx` file reach React as plain HTML, so there's no element to merge
into. Use `buttonVariants()` instead.

### Styling other elements

`buttonVariants()` returns the button's classes as a string, so any element can
look like a button. It takes the same `variant` and `size` options.

```tsx
import { buttonVariants } from "@/components/ui/button"

<a href="/pricing" className={buttonVariants({ variant: "outline" })}>
  Pricing
</a>
```

The classes include the 3px border. The `borderWidth` prop belongs to `Button`, so
for another width add an inline style, such as `style={{ borderWidth: 6 }}`.

## Usage

```tsx
import { Button } from "@/components/ui/button"

export function Example() {
  return <Button variant="outline">Try for free</Button>
}
```

## Props

The button also takes every prop of a native `button` element.

| Prop          | Type                                                                 | Default   | Description                                                   |
| ------------- | -------------------------------------------------------------------- | --------- | ------------------------------------------------------------- |
| `variant`     | `default`, `secondary`, `outline`, `ghost`, `destructive`, `link`    | `default` | How the button looks.                                         |
| `size`        | `default`, `xs`, `sm`, `lg`, `icon`, `icon-xs`, `icon-sm`, `icon-lg` | `default` | The button's height and padding.                              |
| `borderWidth` | `number` or `string`                                                 | 3px       | Border thickness. A number means pixels.                      |
| `asChild`     | `boolean`                                                            | `false`   | Passes the button's styles to its child element.              |
| `className`   | `string`                                                             |           | Extra classes. Where they clash with the button's, yours win. |

## Troubleshooting

**`Unknown registry "@kstile"`.** Your `components.json` doesn't have the `@kstile`
entry. Use the full address instead, or add the entry as shown in
[Installation](/docs/installation/#shorter-commands-with-kstile).

**There's no border, or no focus ring.** Your project is on Tailwind v3, which
doesn't have `border-3` or `outline-3`. The button needs Tailwind v4.

**The CLI says files were skipped because they "might be identical".** The button
is already installed and unchanged. Nothing more to do.

**The button is black, not lime.** It's using your theme's `--primary`. That's
intended. See [Theming](/docs/theming/) for kstile's colours.
