The input has square corners and a 3px border in your text colour, like the
outline button. Focus adds a ring in the same colour, because a ring in your
accent is too faint on a light background. It's 40px tall, so it lines up with
a default button.

The tile variant is a 64px tile with its label inside at the top, and what you
type is set large and light. Use it for short forms, such as signing in or
naming something.

## Installation

The input is React only, and needs Tailwind CSS v4. See
[Installation](/docs/installation/) for the full requirements.

<Tabs>

## Examples

### Tile

Pass `variant="tile"` and a `label`. The label wraps the input, so it needs no
`id`, and a tap anywhere on the tile puts the cursor in the field. `className`
styles the tile; every other prop goes to the input.

<div class={stack}>
  <div class="grid grid-cols-2 gap-2">
    <Input variant="tile" label="Email" type="email" placeholder="maya@fernhill.studio" className="col-span-2" />
    <Input variant="tile" label="Seats" type="number" defaultValue="4" />
    <Input variant="tile" label="Region" defaultValue="eu-west" />
  </div>
</div>

```tsx
<Input variant="tile" label="Email" type="email" placeholder="maya@fernhill.studio" />
<Input variant="tile" label="Seats" type="number" defaultValue="4" />
```

### Label and help text

Give the default input a `label` element of its own, and link any help text with
`aria-describedby`, so screen readers read it too.

<div class={stack}>
  <div class={field}>
    <label class={labelClass} for="demo-email">Email</label>
    <Input id="demo-email" type="email" placeholder="maya@fernhill.studio" aria-describedby="demo-email-help" />
    <p id="demo-email-help" class="text-sm">We only use it for sign-in links.</p>
  </div>
</div>

```tsx
<div className="grid gap-1.5">
  <label htmlFor="email" className="text-sm font-semibold">Email</label>
  <Input id="email" type="email" aria-describedby="email-help" />
  <p id="email-help" className="text-sm">We only use it for sign-in links.</p>
</div>
```

### Invalid

Set `aria-invalid`. The default input's border turns red, and the tile gets a
red square in its top right corner. Write the message in your text colour with a
red square in front, because red text on a light background is too faint to
read. This matches the destructive rows of the dropdown menu.

<div class={stack}>
  <div class={field}>
    <label class={labelClass} for="demo-slug">Project URL</label>
    <Input id="demo-slug" defaultValue="my project" aria-invalid aria-describedby="demo-slug-error" />
    <p id="demo-slug-error" class="flex items-center gap-2 text-sm"><span aria-hidden="true" class="size-2 shrink-0 bg-destructive"></span>Use letters, numbers and dashes only.</p>
  </div>
  <div class={field}>
    <Input variant="tile" label="Project URL" defaultValue="my project" aria-invalid aria-describedby="demo-slug-error-2" />
    <p id="demo-slug-error-2" class="flex items-center gap-2 text-sm"><span aria-hidden="true" class="size-2 shrink-0 bg-destructive"></span>Use letters, numbers and dashes only.</p>
  </div>
</div>

```tsx
<Input id="url" aria-invalid aria-describedby="url-error" />
<p id="url-error" className="flex items-center gap-2 text-sm">
  <span aria-hidden="true" className="size-2 shrink-0 bg-destructive" />
  Use letters, numbers and dashes only.
</p>
```

## Usage

```tsx

export function Example() {
  return <Input type="email" placeholder="maya@fernhill.studio" />
}
```

## Props

The input takes every prop of an HTML `input`. kstile adds these:

| Prop      | Type                | Default   | Description                                                          |
| --------- | ------------------- | --------- | -------------------------------------------------------------------- |
| `variant` | `default`, `tile`   | `default` | `tile` makes the field a 64px tile with its label inside.            |
| `label`   | `ReactNode`         |           | The tile's label, set inside it at the top. Only the tile uses it.   |

## Troubleshooting

**Text zooms in on iPhone.** iOS zooms into any field with text smaller than
16px. The default input uses 16px on small screens and 14px from 768px up, so
keep `text-base` if you override the size.

**The tile's `className` didn't reach the input.** On the tile, `className`
styles the tile itself. Style the input through the tile, for example
`[&_input]:text-2xl`.
