A tile fills the grid cell you put it in, so the layout stays yours. Hover the
templates tile to see it flip.

## Installation

The tile is React only, and needs Tailwind CSS v4. See
[Installation](/docs/installation/) for the full requirements.

<Tabs>
  <TabItem label="CLI">

    See [Installation](/docs/installation/#shorter-commands-with-kstile).

## Examples

### Variants

`default` uses your theme's `--muted` colour. `fill` uses `--primary`, so it
follows kstile's accent.

<div class={grid}>
  <Tile>
    <TileTitle>default</TileTitle>
  </Tile>
  <Tile variant="fill">
    <TileTitle>fill</TileTitle>
  </Tile>
</div>

```tsx
<Tile>
  <TileTitle>default</TileTitle>
</Tile>
<Tile variant="fill">
  <TileTitle>fill</TileTitle>
</Tile>
```

### Title and description

Content sits at the bottom of the tile. Put the description first to show it
above the title.

<div class={grid}>
  <Tile className="col-span-2">
    <TileDescription>Install a component and make it yours.</TileDescription>
    <TileTitle>docs</TileTitle>
  </Tile>
</div>

```tsx
<Tile>
  <TileDescription>Install a component and make it yours.</TileDescription>
  <TileTitle>docs</TileTitle>
</Tile>
```

### Icons

`TileIcon` pins its child to the top right corner. `TileArrow` is kstile's
square arrow for tiles that link somewhere, but any icon works.

<div class={grid}>
  <Tile>
    <TileIcon>
      <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="square" aria-hidden="true"><circle cx="12" cy="12" r="4" /><path d="M12 2v2M12 20v2M2 12h2M20 12h2M4.9 4.9l1.4 1.4M17.7 17.7l1.4 1.4M4.9 19.1l1.4-1.4M17.7 6.3l1.4-1.4" /></svg>
    </TileIcon>
    <TileTitle>light</TileTitle>
  </Tile>
</div>

```tsx
import { Sun } from "lucide-react"

<Tile>
  <TileIcon>
    <Sun />
  </TileIcon>
  <TileTitle>light</TileTitle>
</Tile>
```

### As a link

Use `asChild` to make the tile a link, or any other element. A tile that's a
link or a button gets a ring in your text colour on hover, the same signal as
the button's hover border, and its icon nudges toward the corner.

<div class="not-content py-4">
  <TileLinkDemo />
</div>

```tsx
<Tile asChild>
  <a href="/docs/">
    <TileIcon>
      <TileArrow />
    </TileIcon>
    <TileTitle>docs</TileTitle>
  </a>
</Tile>
```

In Astro, `asChild` only works inside a React component. Children passed from an
`.astro` or `.mdx` file reach React as plain HTML, so there's no element to merge
into. Use `tileVariants()` for the classes instead, as with
[the button](/docs/components/button/#styling-other-elements).

### Flip

Give a tile a `TileFront` and a `TileBack` and it flips on hover and keyboard
focus. Hover this one:

<div class={grid}>
  <Tile variant="fill">
    <TileFront>
      <TileTitle>templates</TileTitle>
    </TileFront>
    <TileBack>
      <TileDescription>Whole pages built from tiles.</TileDescription>
      <TileTitle>templates</TileTitle>
    </TileBack>
  </Tile>
</div>

```tsx
<Tile variant="fill">
  <TileFront>
    <TileTitle>templates</TileTitle>
  </TileFront>
  <TileBack>
    <TileDescription>Whole pages built from tiles.</TileDescription>
    <TileTitle>templates</TileTitle>
  </TileBack>
</Tile>
```

Pass `flipped` to choose the side yourself, for example from a timer. Then hover
and focus leave it alone.

```tsx
<Tile flipped={showBack}>
  <TileFront>…</TileFront>
  <TileBack>…</TileBack>
</Tile>
```

Screen readers only read the front, so keep the back decorative and put nothing
focusable on it. With reduced motion turned on, the faces swap without turning.
Touch screens don't hover, so there a tile only flips through `flipped`.

### In a grid

A tile stretches to fill its grid cell, so size it with your grid's classes,
such as `col-span-2` and `auto-rows-[9rem]`. Outside a grid it's as tall as its
content. A flip tile's faces don't count toward that, so give a flip tile on its
own a height, such as `h-36`.

<div class={grid}>
  <Tile variant="fill" className="col-span-2 row-span-2">
    <TileTitle>2 × 2</TileTitle>
  </Tile>
  <Tile>
    <TileTitle>1 × 1</TileTitle>
  </Tile>
  <Tile>
    <TileTitle>1 × 1</TileTitle>
  </Tile>
  <Tile className="col-span-2">
    <TileTitle>2 × 1</TileTitle>
  </Tile>
</div>

## Usage

```tsx
import { Tile, TileTitle } from "@/components/ui/tile"

export function Example() {
  return (
    <Tile>
      <TileTitle>docs</TileTitle>
    </Tile>
  )
}
```

## Props

`Tile` also takes every prop of a `div`.

| Prop        | Type                  | Default   | Description                                                 |
| ----------- | --------------------- | --------- | ----------------------------------------------------------- |
| `variant`   | `default`, `fill`     | `default` | The tile's colour.                                          |
| `asChild`   | `boolean`             | `false`   | Passes the tile's styles to its child element.              |
| `flipped`   | `boolean`             |           | Shows the back. Leave it out to flip on hover and focus.    |
| `transition` | `flip-up`, `flip-down`, `flip-left`, `flip-right`, `slide-up`, `slide-left`, `fade` | `flip-up` | How a flip tile turns to its back. |
| `className` | `string`              |           | Extra classes. Where they clash with the tile's, yours win. |

| Part              | Renders | Use                                       |
| ----------------- | ------- | ----------------------------------------- |
| `TileTitle`       | `div`   | The large heading at the bottom.          |
| `TileDescription` | `p`     | Smaller text, shown above the title.      |
| `TileIcon`        | `span`  | Pins an icon to the top right corner.     |
| `TileArrow`       | `svg`   | kstile's square arrow for link tiles.     |
| `TileFront`       | `div`   | The side shown at rest on a flip tile.    |
| `TileBack`        | `div`   | The side shown on hover, focus or `flipped`. |

## Troubleshooting

**The tile blends into the page.** Your theme's `--muted` is close to its
background. Use `variant="fill"`, or set the colour with a class such as
`[--tile-bg:var(--color-card)]`.

**There's no focus ring or hover ring.** Your project is on Tailwind v3, which
doesn't have `outline-3`. The tile needs Tailwind v4.

**The flip doesn't turn.** Reduced motion is on in your system settings, so the
faces swap instead. That's intended.
